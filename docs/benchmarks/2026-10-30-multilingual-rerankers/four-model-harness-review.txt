# Four-model harness review

## Verdict and scope

Ready to freeze and execute the declared bounded comparison. No open Critical, High, Medium or actionable Low defect remains in the inspected scope. This verdict covers the protocol and helper code; model results, actual cgroup enforcement, native draining under real inference, measurement completion, and adoption remain unproven.

The review started with PLAN.md, server.py, benchmark.py and corpus.json, then included build_corpus.py, analyze.py and run_matrix.py as the coordinator added the executable analysis and launcher. All paths below are relative to docs/benchmarks/2026-10-30-multilingual-rerankers/. Base HEAD is e81b21ffc907218800e1fa9646abf74d0c81b7e7. Helpers were untracked and changed during review; the final hashes below identify the accepted code. The reviewer changed only this report. No model weights were loaded, no model inference ran, and no private corpus, database, GitHub or production service was accessed.

Writing depth: medium standalone reference for the maintainer. Prose, terminology, exact paths, facts and evidence limits were checked.

## Fresh verification

All five helper Python sources compiled in memory. The project's benchmark.py --validate-only command passed: 96 questions, 48 DE/48 EN, 24 families, all eligible for the actual adapter. Actual exit 0.

Full analyze.py was executed with in-memory files for all four models and all three rounds. One scenario censored one raw observation per mode; another censored every raw observation. Both processed 2,688 mocked rows, kept zero-scored quality null, retained 45 performance timeouts per cell in the fully censored scenario, and exited 0. No mock files were written. These numbers validate analysis mechanics and are not model measurements.

The tokenizer-only probes loaded tokenizer files, not neural models. The original race probe exited 0 after recording its errors; the corrected locked probe asserted zero errors and exited 0. The original analyzer failure and its corrected complete runs are distinguished above.

## Replayable in-memory analysis probe

Run from the reviewed repository. This script uses synthetic rows and replaces file access with memory-backed paths; it writes no files and executes no inference.

```sh
python3 -B - <<'PY'
import json,sys
from pathlib import Path
source=Path('docs/benchmarks/2026-10-30-multilingual-rerankers/analyze.py').read_text()
for scenario in ('one-censored-per-mode','all-raw-censored'):
 fs={};written={};goldmetric=dict(top1=True,recall3=1.0,all_sources3=True,mrr=1.0,ndcg3=1.0)

  def __truediv__(self,x):return MemoryPath(self.s+'/'+str(x))

   rows=[];seen=set()

    v=dict(model=name,round=rnd,mode=mode,case_id=str(i),family='f'+str(i//4),language='de' if i%2==0 else 'en',split='prior-diagnostic' if i<32 else 'new-unseen',input=ids,order=ids,expected=expected,metrics=None if censored or not expected else goldmetric,elapsed_ms=30000 if censored else 1,error='ReadTimeout' if censored else None,response=None if censored or not raw else dict(results=[dict(index=j,relevance_score=s) for j,s in enumerate(scores)],measurement=dict(native_scores=scores,prepare_ms=.1)),**extra)
```
